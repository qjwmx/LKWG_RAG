# 性格与个体值

## 一、性格

性格会**提升一项能力 10%、降低另一项能力 10%**。共 25 种，另有不做任何修正的中性性格。

| 大胆 | 物攻 | 物防 |

**中性性格**（如「实干」）不做任何修正，适合不想牺牲任何一项的场合。

### 怎么选性格

- **物攻手** → 固执（+物攻 -魔攻）或 勇敢（+物攻 -速度，用于后手）
- **魔攻手** → 聪明（+魔攻 -物攻）或 冷静（+魔攻 -速度）
- **速攻手** → 开朗（+速度 -魔攻）或 胆小（+速度 -物攻）
- **肉盾** → 忧郁（+生命 -物防）需谨慎，通常选 悠闲/懒散 补防

原则是：**降低的那一项要选这只精灵用不到的**。物攻手降魔攻没有代价，降速度就有代价。

## 二、个体值（天赋）

个体值决定六项能力的成长上限，方向通常标注为三项，例如「生命、魔攻、速度」。

常见的分配思路：

- **速攻型**：生命 + 主攻属性 + 速度
- **耐久型**：生命 + 物防 + 魔防
- **平衡型**：生命 + 主攻属性 + 对应防御

个体值方向的取舍本质是：**在"能不能先手"和"能不能扛住一下"之间选**。
速度线能否过某个关键对手，往往决定一个阵容的成败。

## 三、搭配建议

1. 先确定这只精灵在队伍里的**定位**（速攻 / 耐久 / 平衡），再定性格与个体值。
2. 性格与个体值要**一致**：给物攻手配「冷静」（+魔攻）是自相矛盾的。
3. 速度个体值不是越多越好——如果这只精灵本来就不需要先手（例如靠后手反打），
   把个体值投到耐久上收益更高。
