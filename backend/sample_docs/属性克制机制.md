# 属性克制机制

## 一、属性总览

《洛克王国：世界》共有 **19 个属性**：

普通、草、火、水、光、地、冰、龙、电、毒、虫、武、翼、萌、幽、恶、幻、机械、无。

其中「无」不参与克制计算，通常出现在特性类技能上。

## 二、克制关系怎么算

每次攻击的最终倍率由**攻击方属性**与**防守方属性**共同决定：

| 情况 | 倍率 |
| --- | --- |
| 攻击方属性克制防守方属性 | ×2 |
| 攻击方属性被防守方属性抵抗 | ×0.5 |
| 无克制也无抵抗 | ×1 |

**双属性精灵的倍率是相乘的**，这一点最容易算错：

- 火系打「草/冰」双属性 = 2 × 2 = **×4**
- 火系打「水/草」双属性 = 0.5 × 2 = **×1**
- 一克一抗会互相抵消，所以双属性不等于更脆

## 三、常见克制速查

- **火** 克制 草、冰、虫、机械；被 水、地 克制
- **水** 克制 火、地、机械；被 草、电 克制
- **草** 克制 水、光、地；被 火、冰、毒、虫、翼 克制
- **地** 克制 火、冰、电、毒；被 草、水、冰、武、机械 克制
- **电** 克制 水、翼；被 地 克制
- **冰** 克制 草、地、龙、翼；被 火、地、武、机械 克制
- **武** 克制 普通、地、冰、恶、机械；被 翼、萌、幻 克制
- **龙** 只克制 龙；被 冰、龙、萌 克制
- **机械** 是**肉盾属性**：只被 火、水、武 克制，却抵抗 10 种属性
- **普通** 不克制任何属性，只被 武 克制，抵抗 幽

## 四、组队时怎么用

1. **先看核心精灵的弱点**：它被哪些属性克制，就要在队伍里准备能处理这些属性的队友。
2. **再看队伍的攻击覆盖**：理想情况下队伍的攻击属性应覆盖大部分常见属性，避免出现"打不动"的盲区。
3. **不要只看单只精灵的属性**：双属性会显著改变克制关系，必须按相乘规则实算。
