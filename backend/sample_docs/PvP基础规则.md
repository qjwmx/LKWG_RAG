# PvP 基础规则

## 一、阵容构成

一套 PvP 阵容由 **6 只精灵**组成，每只携带 **4 个技能**，全队共用 **1 个血脉魔法**。

阵容数据里通常包含每只精灵的：

- **性格** —— 影响两项能力的 10% 增减
- **血脉** —— 决定可用的血脉技能
- **个体值方向** —— 通常标注 3 项
- **4 个技能**

## 二、胜负条件

对局以**击倒对方精灵**推进，先达成条件的一方获胜。具体回合与击倒数的规则以游戏内当前版本为准——
赛季更新可能调整，**不要以旧攻略为准**。

## 三、轮转（Switch）

轮转是 PvP 的核心操作：在不利对位时换上更合适的精灵。

要点：

1. **换人要付出代价**：对手会获得一次免费行动，所以要换得有价值。
2. **预判换人**：读对手要换谁，提前用克制它的技能。
3. **别把所有弱点集中在一只精灵身上**：一套阵容如果 4 只都被同一属性克制，会很被动。

## 四、组队的基本框架

一套能打的阵容通常包含：

| 角色 | 作用 |
| --- | --- |
| 首发 | 开局建立优势或试探对手 |
| 输出核心 | 承担主要伤害 |
| 副输出 | 补属性盲区 |
| 轮转手 | 处理对核心不利的对位 |
| 收割手 | 残局清理 |
| 功能位 | 状态、回复或控场 |

不是每套阵容都必须严格按这个分工，但**完全缺某一环**（例如没有任何处理核心弱点的精灵）的阵容很难打。

## 五、数据口径说明

本项目里的阵容数据来自 **BWIKI 的玩家投稿**，请注意：

- 它**不代表对局使用率**，也不代表强度排名；
- 它是"有玩家这样配过"，不是"这是版本答案"；
- 游戏进入新赛季后，旧投稿可能已经过时。

因此系统给出的推荐是**参考资料**，不是权威结论。实战前请结合当前赛季环境自行判断。

## 六、赛季

游戏采用赛季制。赛季更新通常会：

- 新增精灵与技能
- 调整部分精灵的数值或技能效果
- 改变环境主流阵容

**跨赛季的攻略要谨慎参考**。项目里的数据带有 `submitted_at`（投稿日期），
判断时效性时以它为准。
